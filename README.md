# Unit-Converter
A simple command line application to convert units written in rust, 
as a Software Test assignment.

Supports the following units, with metric units allowing for multiple
scales (e.g. Meter -> millimeter / kilometer / etc):

### 1. Temperature
- Kelvin
- Celsius
- Fahrenheit
### 2. Mass
- Grams
- Ounces
- Pounds
- Stones
### 3. Length
- Meters
- Inches
- Feet
- Yards
- Miles
### 4. Area
- Sq. Meters
- Hectares
- Sq. Inches
- Sq. Feet
- Sq. Yards
- Sq. Miles
- Acres
### 5. Volume
- Liters
- Cb. Meters
- Teaspoons
- Tablespoons
- Cups
- Pints
- Gallons
